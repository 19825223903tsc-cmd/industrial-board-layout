# 中文展板文字排版

本文件是中文版每次构图时的必读规则。主要展板文案固定为中文，不根据对话语言改成英文版；英文品牌、型号、单位和用户要求保留的专名可作为混排。完整英文版使用独立的 industrial-board-layout-en，并用真实译文重新排版。

## 中文层级与密度

- 用当前项目真实中文确定主标题、分区标题、说明、图注各自的字号、行高和黑度。先测实际可用中文字体及字形，不能用英文平均字符宽度估算中文容量。
- 中文短标题不自动放大到英文长标题同宽。图组的共享边缘与编号列决定起点，标题长度决定自身占用；不靠加字距或空格把短标题撑满。
- 正文和图注自然左对齐，避免两端强制拉字造成灰度不均。行高依据字体、字号、观看距离与内容密度试排，没有全项目固定倍数。
- 编号、标题、英文品牌/型号拆成独立元素；同排编号、标题按首行基线检查。中文与Latin视觉大小、黑度、基线分别校正，不把相同字号当作视觉对齐。

## 中文断行

- 检查行首闭标点、行末开标点、括号/引号配对以及不必要的标点悬挂。脚本仅做常见边界初检，仍须放大查看真实PNG。
- 避免一两字短尾行、标题的无意义断词和将一个意思拆成孤行。先改栏宽、文本框高或模块关系，再提出可选精简文案；不擅自改掉用户原文含义。
- 型号、英文专名、尺寸值与单位作为语义单元处理。CJK与Latin混排的间距来自字体或明确排版，不用连续空格定位。
- 并排图注分别写清内容后测量首行、末行基线；需要共底时重新分配可读的行长/文案体量，不能填充假字或强塞空行掩盖差异。

## 空间与交接

图间、组间、标题至图及图下注距分别定义；同类关系复用细间距，图注不能挤成图片的一部分。中文版按实际汉字体量重新决定栏宽与附近图框。保留图框、基线和实际字形边界三种检查，不强迫所有模块同高。

layout.json 使用 canvas.language=zh-CN，并为标题、正文、图注显式设置语言与实际字体。渲染入口会补充缺省语言/中文字体；若输入是完整英文版则报错，改用英文Skill，不偷偷翻译或缩小字号。

生图提示词明确主要文案为中文、标题/正文/图注层级、编号起点及跨区共同基线。必要时为英文品牌/型号单独标记保留原文；不自动增设英文副标题。文字策略要写入本项目提示词，不能只写“中文整齐”。模型文字准确性与像素级对齐仍在生成后核对。
