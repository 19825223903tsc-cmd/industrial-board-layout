# 文字与图片共同构图

文字是有面积、节奏和归属的版面内容。不能先画满图片区，再把说明塞入空隙。

## 先形成内容清单

按实际项目记录每项内容：角色、原始素材、要表达的信息、优先级、与哪张图关联、文本状态（用户原文/基于可见事实拟写/待提供）。核心观点应有图片或可靠材料支持。只有成品图时可解释可见形态与材质表现，不编造调研、草图推演、机构或性能；也不要为了“展板感”硬添研究栏目。

项目名、产品类型与核心主张要区分。未知型号用中性产品类型；编辑性标题标明试拟，不能当作产品正式名称。

## 在草图阶段配置文字

- 给标题、副标题、分区标题、正文、图注分别定义字体、字号、行高、字重与颜色；角色可按内容合并，不强制五级齐全。
- 尺寸从阅读条件和画布推导。标题要能建立入口，但不能只因空白多就放得像海报。根据项目决定文字与主图谁先被读到。
- 在每个文本块记录 x/y/w/h、实际文案、字号、行高、预计行数和所属图片/图组。暂无文案时使用明确标注的内容摘要和预估长度，不用无意义横线冒充完成的文字规划。
- 先以真实文本试排。中文检查标点悬挂、行首标点、孤行与不自然断词；英文尽量按词换行，不把单词拆成逐字排列。双语不要机械等字号，应校正视觉字重和长度。
- 文案变长时重新调整栏宽、图文关系、分组或分板；可提出精简，但不擅自删除用户核心信息。不要无下限缩小字号。
- 编号与标题拆分为独立文本元素，共用明确的编号列和标题起点，避免靠空格控制对齐。
- 为同组图注设置共同基线或一致图下注距，并在布局清单明确采用哪一种。图注与对应图的距离应小于与邻图的距离。
- 标注编号、引线与短说明形成明确对应；引线终点指向实际部位，避免穿过正文或关键轮廓。不为装饰添加无意义技术线。
- 图片空白不等于安全文字区：叠字前检查真实轮廓、阴影和背景变化。必要时改布局，不覆盖关键功能与细节。

## 先测量，再目视

线框至少显示实际标题尺度、正文换行和图注位置，文字不能都使用同样的小号标签。脚本测量只能验证文字框容纳、约定锚线及几何范围；中文断行、视觉重心、渲染字体替换和图像归属仍需目视检查。

渲染字形与编辑源字体要一致，或明确替代字体。PNG是预览，SVG文字保持可编辑；在其他软件打开SVG时可能因字体替换重新换行，不能承诺跨软件结果完全相同。

## 图间距与组间节奏

选定当前项目的间距尺度，再排图框。同组图使用相同的横向/纵向图间距；跨组若需更宽，设独立命名的组间距，建立清楚关系，不让每个缝隙成为任意数。间距按项目选择，不使用通用固定值。例如用户偏好细间距的A3案例采用图间3mm、图下注距3mm、标题框到图片3mm、章节6mm；这些数值仅适用于该案例。

同时核对相邻图像边界、图框/背景面板、图注的关系。不能用图片白底或黑边把数值间距伪装成视觉间距；若有效画面内含大边距，第三轮要实际查看。改变图框宽度时按比例缩放主体，不拉伸，不裁去产品来凑齐。

把全部实际相邻的图片对加入horizontal/vertical的gap_rules，不能只检查图下注距。高主图与右侧上下堆叠图的两个间隙都需覆盖；同排有三张/四张图要逐缝检查。composition_signals.py可用纵向扫描带枚举横向相邻图片与间距，辅助发现遗漏关系；生成输出须再次核对实际图边，不能拿线框数值当输出数值。
