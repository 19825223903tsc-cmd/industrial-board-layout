# 根据产品构建构图

目标是从产品和内容推导版面，而非把产品塞入预设模板。沿用的是对齐纪律和信息层级，不是区域坐标。

## 先分析五项输入

- 形态：横向、纵向、紧凑块体、环形/开敞，或多部件系统？主体可见轮廓的长宽与负空间如何？区分产品轮廓和原图四周空白。
- 视觉方向：视角、朝向、伸展部件、运动或操作方向如何？给其留出合理空间，不以裁切、拉伸适配预设图框。
- 核心表达：最应看懂的是外观材质、结构机制、人体关系、场景流程、模块组合，还是系列差异？若上下文已明确直接采用，否则简短说明合理假设。
- 素材条件：实际有哪些图片与文案，各自质量、数量和比例怎样？没有过程素材，不预留成排“形态研究”来伪造丰富度。
- 展示条件：尺寸、方向、阅读距离、信息量、品牌和用户指定参考。已有画布约束优先，内容过载时调整结构或页数，不暗改交付尺寸。

## 从内容推导空间

这些是可用的推导例子，不是有限模板菜单，更不是产品类别与构图的一对一映射：

- 细长产品可能适合宽幅或竖向贯穿图，其余说明沿有用的边缘展开。若重点是操作，也可以用连续场景作为主轴。
- 紧凑产品若强调外观，可用偏置大透视与少量局部；若强调内部构造，剖视或爆炸关系可成为主要视觉锚点。
- 穿戴与人体辅助产品，使用者与产品的比例关系可能比单独产品渲染更重要，可围绕动作组织信息。
- 模块或系列产品可能需要并列、矩阵、组合关系与共同尺度，不强行选择唯一中心大图。
- 服务或系统产品可能以真实场景或操作顺序串联关键触点，文字跟随情节，不挤入无关侧栏。

同一产品因讲述目的不同可以产生不同构图；不同产品也可能在充分理由下采用相似构图。不要为了表面变化随机挪模块，也不要因产品同属一类而直接复用坐标。

## 收敛为可执行版式

1. 用一句话明确本板最重要的信息。
2. 根据内容考虑少量实质不同的空间组织，比较焦点、动线、形态适配和文字容纳能力。通常直接选最有依据的一种；用户要比较时再输出备选，不强制增加交付或生图次数。
3. 决定画布内视觉锚点的位置与尺度，接着安排直接支持该重点的图文组，最后安放次要内容。
4. 依据所选空间关系建立网格、锚线、列跨度、文字宽度和纵向节奏。网格服务构图，不强制统一列数、主图占比或侧栏宽度。
5. 为本项目新建 JSON。模块数量、名称、尺寸、顺序都由实际内容决定；不要求凑齐示例的 A–I 或任何固定章节。
6. 渲染后从全板和局部检查，必要时更换构图而非只微调对齐。非对称、跨区、环绕等布局也要保持明确锚线和不互相误认的归属。

向用户简短说明“产品/内容特点 → 构图选择”的理由，并给出实际线框，不只报告某种风格名称。交给生图的提示词必须来自本次 JSON 和实际素材，不能沿用上一项目的中心偏右、左侧栏或底部序列指令。

审核构图判断时读取 [composition-evaluation.md](composition-evaluation.md)，比较内容适配与取舍；少素材决策按 [product-evidence.md](product-evidence.md) 约束，不为丰富版面生成未见产品状态。

## 工业设计叙事与素材充分性

先定义图组分别回答的问题，例如整体形态、表面与连接、操作姿态、人体关系或模块配置。按当前产品选择有证据的图组，不设固定图数。区分完整视角、细节裁切、同图重复及不同系统配置；不能靠重复照片、无依据草图或散列参数制造丰富度。用户要求联网采集时先检查官方图库、说明书与设计资料，核对同型号、颜色、附件和代际。官方组合示例不等于设计迭代。

检查实际素材落位后的画面边缘：方图contain进宽框会使实际图边与图注不齐。明确背景留白、产品可见轮廓、有效图像边界与框边分别如何对齐，必要时改图框比例；不得只凭占位矩形的测量通过。可做明确标为校样的原图落位预览用于验证，它仍不是生图成品。
