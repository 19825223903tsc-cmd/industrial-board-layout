# 从排版线框交给生图

准备本技能默认的构图引导包时读取本文件。线框指页面布局，不是产品造型线稿。

## 从参考提炼排版原则，而非固定布局

用户提供的六张参考呈现出以下可借鉴关系。以下位置描述仅记录参考观察，不是新项目的布局指令；新构图以产品分析为先：

- 狭窄侧栏容纳语境图、CMF、设计说明；正文左对齐，分区标题短且低调。
- 一张较大的产品透视图形成中心，轮廓留白优先，附近有少量引线。
- 形态探索、方案演变、细节与交互按功能分组。组内缩略图尺度接近、间距重复，图注紧贴各图。
- 下沿常以横向迭代序列收束，或者用细节/交互/机构几组小图收束；材料不足时删除整组，不编造过程。
- 留白与细分隔线组织层级，图片占主导，避免把所有模块做成厚边框卡片。
- 其中部分参考是多张展板或产品图与展板的拼接：提取单张展板的关系，不把整张拼图当成成品比例。不把“产品图”等叠加标签放入成品。

迁移网格、比例和层级，不迁移原图的品牌、文案或产品身份。浅紫、浅蓝等强调色由实际产品与品牌决定。

## 线框交付

先完成产品驱动构图分析，整理真实素材数量，选择必要模块与阅读顺序，再从零写本项目布局清单。不得直接加载示例再换素材。按 [layout-schema.md](layout-schema.md) 把文本和图片区分为自由元素，记录位置、文字内容、字号行高、素材来源与关联关系；每个文本要有可容纳其长度的真实空间。清楚区分：

- 产品身份图：唯一用于约束实际产品形态的素材。
- 风格参考：用于线条、渲染和版式气质。
- 线框：用于画布比例、模块位置、相对大小和留白。

提供可编辑 SVG、对应 PNG 和 JSON 坐标清单。排版线框是设计中间件，不是最终展板。无实际素材时在交付说明标明通用示例，不能虚构项目事实。

为实际项目新建 layout.json，写入分析后决定的模块与坐标，再使用脚本渲染：

```text
python scripts/render_wireframe.py /absolute/project/layout.json --out /absolute/output-directory
```

`assets/example-board-wireframe.json` 仅供了解数据结构，不是默认布局。新项目的文字测量与 PNG 渲染需要 Pillow；依赖不足时先检查实际可用运行时。按本项目画布选择比例，示例尺寸不构成比例约束。脚本输出标注版与无调试坐标版；后者供生图参考，但仍含示意框线，需在提示词里要求移除。

## 生图交接包

先确认当次生图工具的实际参考图数量限制，选定可用原图及取景映射，再完成五轮审核。删减参考图后不能让失去依据的图位由模型脑补。与线框一起输出提示词文件，包含：

1. 各输入图的角色与优先级。产品身份由实际产品图约束，几何关系以线框为准，视觉风格由参考图支持。
2. 产品一致性约束：按 [product-evidence.md](product-evidence.md) 对每个图位严格限定已见视角与状态，不为素材少而扩展未知外观。轮廓、结构、配色、功能部件；只允许用户已授权的改动。
3. 模块内容映射：细节图绑定source_region与区域ID，并明确目标特征和易误取部位，附源图标记说明。主图、细节、视图、交互或发展过程分别需要什么。用户没有提供的数据与机制不伪装成事实；必要时留空或标注为待确认概念演绎。
4. 画布比例、主次、锚线、间距、阅读顺序；生成后移除占位框、叉线、占位字和坐标。
5. 文字策略。说明目标语言、真实文案或明确标注的长度假设、标题/正文/图注层级、断行与对齐意图。生图模型应移除占位标签，并按目标文案呈现文字；未给正文时保留合理文字区，不生成密集假字。不要自动把后置精确文字排版纳入交付。
6. 约束优先级。优先保持产品身份与主要构图区关系；说明哪些标题起点、图组边界、阅读顺序必须保留，哪些细小间距、阴影、笔触可在不破坏层级时调整。相对位置与比例需用自然语言解释，不只给坐标。

交接前必须完成 [five-pass-review.md](five-pass-review.md) 的五轮自检并通过版本门槛。未审第一版仅为草稿。用户仅要求准备线框/交接包时，交付经审查的引导包及记录。用户要求实际生图且实际产品或允许的概念已明确时，使用可用的图像生成工具与相应技能，不要求重复授权；不要在缺少产品图时擅自替用户选参考里的产品。

提交前按 [model-validation.md](model-validation.md) 锁定实际参考数量、角色、图谱映射与输入指纹，生成后按其逐项记录真实结果。

## 生成后复核

比较实际图与本项目线框：主要视觉锚点占比、各组边界、阅读顺序、同排图注及留白是否保留。只检查实际存在的模块，不默认要求侧栏或底部序列。对照真实文案检查字号、换行、文本体量与图像归属，不只检查图片区。检查产品身份、结构、文字与标注真实性。生图参考不能保证像素级坐标或文字准确。定位偏差后优先改善引导图清晰度、文案体量与提示词优先级；不要自动转为最终展板拼版。不能仅凭提示词声称结果已经精确对齐。


本包默认交接的主文案语言是en。每次先读language-typesetting.md；完整的另一语言版本使用另一独立技能，不直接沿用本文字框。
