# 构图引导包验收与下游边界

## 默认交付

本技能为生图模型规划展板，默认交付线框SVG/PNG、布局JSON、构图说明和提示词。可编辑文字用于可靠表达引导图中的层级与位置，不意味着承接最终展板文字制作。用户仅调整规则或要求建议时，按其范围交付。

“试一下”默认检查当前产品的引导包。若用户已明确要求本次连同生图一起试跑，则继续已有范围；不要重复询问。成品拼版、印刷、后置文字不作为自动补救方案。

## 五轮自检为交付前置条件

所有引导包先执行 [five-pass-review.md](five-pass-review.md)，检查当前同一版并通过review_gate.py。以下验收内容由执行代理在五轮中完成；不能以用户尚未指出问题或局部检查通过代替审查。未通过时只能提供明确标注的草稿及待解决项，不能释放生图交接。

## 引导包验收

- 产品适配：能说明产品特征与当前构图之间的关系，无固定模板残留。
- 产品证据：素材少时主动减少图位，逐个核对已有视角和可见裁切；未见背面、内部结构、状态不得交由模型当作真实产品补齐。有局部取景时必须查看源图标记说明。
- 内容真实：图片/文案来源及假设清楚，缺少素材的模块未被虚构填充。
- 文字适配：中文、英文或双语各自的层级、体量和换行清楚，编号列、标题起点和图文归属明确。
- 几何关系：线框中的边缘、首末基线与间距有意图且可检查；无意外越界、重叠、溢出。光学判断仍需目视。
- 生图可用：提供易读取的PNG；图框只是区域引导而非成品装饰。角色、画布比例、阅读动线、主要相对位置与提示词一致。
- 约束可执行：提示词区分产品身份、主要空间关系、文字层级与可自由发挥的材质/笔触细节。不能只依赖坐标数字让模型理解版面。
- 版本一致：PNG、SVG、JSON和提示词来自同一布局；报告已测量、目视或未验证的内容，避免把结构检查等同于设计成熟。

## 用户另行要求实际生图

把产品图、引导图与提示词交给可用图像生成工具；明确输入角色。按 [product-evidence.md](product-evidence.md) 逐图位检查实际结果的产品身份、部件、结构、视角及源图取景，然后再评估区域主次、阅读顺序、文字容量与对齐表现。错误产品图记为不通过，不能以构图好看抵消。发现漂移时，区分是线框不清楚、指令优先级冲突、文字过密还是模型执行偏差，再做有针对性的调整。

本技能的验收重点是引导信息是否清晰有效。生成稿不能逐像素复现不等于线框坐标有误；线框坐标正确也不等于模型已经理解。若用户另行要求精确成品，可交给排版工作流承接，不自动更换任务目标。

## 验证技能

用不同产品、同一产品不同讲述重点、少量素材及中英文版本检验：视觉锚点和图文组是否从输入推导，提示词能否明确说明关键关系。假设输入可用于检查结构，不计为真实产品试用；仅比较坐标不同不能证明构图有效。

脚本回归：`python -m unittest discover -s tests -p "test_*.py"`（需要Pillow），同时覆盖文字渲染与五轮审查门槛。检查换行、溢出、越界、ID、对齐与语言字体。字体不可用而跳过的测试不计为已验证。行为验证应关注模型拿到引导包后的结果，仅在用户已要求生图测试时执行下游生成。
