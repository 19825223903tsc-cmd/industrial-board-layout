# Industrial Board Composition Skills

Plan a product-specific exhibition board before image generation. Two independently installable Codex skills handle Chinese and English typography, source-bound framing, thin gutters and cross-region alignment.

Download [English v14](downloads/industrial-board-layout-en-v14.zip) or [Chinese v14](downloads/industrial-board-layout-zh-v14.zip). Extract the skill folder into `~/.agents/skills/`, preserving its contents. See the [official Codex skills guide](https://learn.chatgpt.com/docs/build-skills). Python 3, Pillow and an available language-appropriate font are needed for scripted rendering.

Upload product images, then invoke `$industrial-board-layout-en`. Specify paper size, orientation, information priorities and actual copy. The output is a reviewed wireframe, framing notes and a generation prompt. Explicitly request image generation if you want the next stage.

Chinese typography handles punctuation and mixed CJK/Latin copy. English typography handles word wrapping, heading case, long model names and caption line length. The composition adapts to the product and available evidence.

Five review passes precede the handoff. Three reviews follow image generation. Do not fabricate unsupported parts, views, mechanisms, specifications or research history.

All displayed product boards are source-photo placement proofs. They are not accepted image-model outputs. Passing geometric checks does not prove aesthetic quality, correct generated text or stable model compliance. No quantified retry reduction is claimed.
